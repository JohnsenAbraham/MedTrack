MedTrack – AWS Cloud-Enabled Healthcare Management System

A demonstration healthcare web application designed to showcase cloud integration with Python Flask, Amazon DynamoDB, Amazon SNS, and AWS EC2 with role-based access for Patients and Doctors.

Appointment Scheduling

Patients easily select an attending doctor, preferred date, and time slot with real-time status tracking (Pending, Confirmed, Completed, Cancelled).

🩺

Doctor Consultation Workspace

Accredited physicians review assigned patient appointments, confirm bookings, and record clinical diagnosis notes upon consultation completion.

📋

Personal Medical Records

Confidential diagnosis records are accessible strictly by the patient and their consulting physician using secure role-based authorization.

🔔

Amazon SNS Alerts

Automated event-driven notifications dispatched for appointment bookings, confirmations, cancellations, and doctor diagnosis submissions.

System Architecture & AWS Cloud Integration

Engineered with a repository abstraction layer supporting dual-mode execution: local SQLite for offline development and Amazon DynamoDB + Amazon SNS for AWS cloud deployment.
