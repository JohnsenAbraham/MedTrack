Architected for AWS Cloud Enterprise Resiliency

Built in alignment with the AWS Well-Architected Framework: Reliability, Security, and Operational Excellence.

⚡

AWS DynamoDB Serverless NoSQL

Multi-table architecture storing patient rosters, appointments, structured vitals, and diagnoses with Global Secondary Indexes (GSIs).

🔔

AWS SNS Real-Time Push Alerts

Event-driven notifications alerting patients when visits are confirmed or cancelled, and when doctors publish e-prescriptions.

🔒

AWS IAM Zero-Trust Security

Role-Based Access Control (RBAC) separating Doctors, Patients, and Hospital Admins with immutable HIPAA audit trail logging.

🖥️

AWS EC2 Multi-AZ Hosting

Production-grade Gunicorn WSGI workers reverse-proxied behind Nginx for high-throughput concurrency and SSL termination.

🛡️

Fault-Tolerant Retries & DLQ

Exponential backoff with jitter on cloud database throttling and automated Dead Letter Queue (DLQ) routing for message resilience.

📊

AWS CloudWatch Observability

Live structured JSON health monitoring, application latency metrics, and HIPAA compliance audit log streaming.
